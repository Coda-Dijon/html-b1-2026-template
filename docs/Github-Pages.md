# Publication sur Github Pages

## Activer les Pages Github

Nécessite d'être administrateur du dépôt (repository).
- La personne qui a créé le dépôt

Dans Github, à partir du dépôt
- Paramètres (Settings)
- Pages
- Build and deployment
    - Source
    - Deploy from a branch
- Branch
    - main
    - `/ (root)`

## Afficher l'URL du site déployé

Dans Github, à partir du dépôt
- A propos (About) -> Bouton `⚙️` sur la partie droite de l'écran
    - Modifier les détails du dépôt (Edit repository details)
        -  Site Web (Website)
            - Utiliser votre site Github pages (Use your GitHub Pages Website)
